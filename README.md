# Encha Matcha — Single-Page Website

A responsive single-page website designed and developed for Encha, an organic matcha brand.

This project combines UX/UI design with front-end development, focusing on clean visual design, responsive layouts, interactive functionality, accessibility, and usability.

## Project Overview

The goal of this project was to create an engaging single-page website for an organic matcha brand while applying front-end development and UX/UI design principles.

I began with a low-fidelity wireframe to plan the page structure and content before developing the final website.

## My Role

**UX/UI Designer & Front-End Developer**

- Planned the website structure and content layout
- Created a low-fidelity wireframe
- Developed the interface using semantic HTML, CSS, and JavaScript
- Created a matcha-inspired visual design system
- Implemented light and dark mode
- Developed interactive product content
- Added JavaScript-based functionality
- Implemented contact form validation and error handling
- Tested and refined the website for usability and accessibility

## Key Features

### Light / Dark Mode

Implemented a light and dark mode toggle using CSS variables and JavaScript.

### Interactive Product Display

Created an interactive product display using JavaScript objects and DOM manipulation.

### Number Guessing Game

Added a JavaScript number guessing game as an interactive element.

### Validated Contact Form

Implemented client-side form validation and error handling to provide users with feedback when submitting the form.

### Responsive Design

Designed the website to provide a consistent experience across different screen sizes and devices.

### Accessibility

Applied semantic HTML and made refinements to improve usability, interaction states, and accessibility.

## Design Process

### 1. Wireframing

Created a low-fidelity wireframe to plan the page structure, content hierarchy, and placement of interactive elements.

### 2. Visual Design

Developed a calm green color palette inspired by matcha and tea leaves.

CSS variables were used to manage the color system and support the light/dark theme.

### 3. Development

Built the final website using:

- Semantic HTML for structure
- CSS for layout, styling, and theming
- JavaScript for interactive functionality

### 4. Testing & Refinement

Tested the website for:

- Form validation errors
- JavaScript console errors
- Usability
- Alignment
- Hover states
- Accessibility

I then refined the interface and interactions based on the results.

## Challenges & What I Learned

One of the main challenges was managing multiple interactive JavaScript features within a single-page website.

This project strengthened my understanding of:

- Event handling

- CSS variables
- Theme switching
